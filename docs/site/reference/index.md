# Reference

## Public API

| item | what it is |
|---|---|
| `char.*` ops | the contract surface, implemented over `std::char` |
| Unicode semantics | predicates and case transforms follow the Unicode Character Database |
| `code_point` / `from_code_point` | expose scalar values across the FFI boundary |

## Crate

| crate | role |
|---|---|
| `handl-plugin-lib-char-native` | Rust backend for `char` |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # cargo test
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
